    USB-FIRST SETUP

    Readiness & recovery

      Commissioning and physical checks

      Keep contactor and mains wiring disconnected. Complete docs/bench_checklist.md, including actual GPIO47 polarity, COM–NO continuity and boot/reset pulse measurements. A software status cannot verify these measurements.

      Only after completing the physical checks, USB arm records commissioning. The separate enable_output operation leaves DISABLED selected. Neither action is available through this page.

      Tesla reauthorization

      Use the laptop helper's fresh consent and USB provisioning flow. Reuse your registered application and public-key hosting. Do not replay an old refresh-token backup; the ESP32 is the sole runtime refresh owner. Replacement provisioning resets commissioning and dry-run.

      python tools/onboard.py run --port PORT

      Replace PORT with your USB port, such as COM8 or /dev/ttyACM0. Enter secrets only in the helper's local hidden prompts.

      Wi-Fi, local certificate, or storage problems

      The board requires 2.4 GHz Wi-Fi and the reserved LAN address used in its certificate. Inspect the USB diagnostics if HTTPS is unreachable:

      python tools/onboard.py usb diagnostics --port PORT

      Use your per-device local CA and matching HTTPS address. Do not disable certificate checks or erase NVS to clear an error. Secret/network/certificate replacement uses the documented USB provisioning flow.
